01 / The short version

Built for visitors and editors.

The goal

Give visitors a clear way to discover the club and its student games, while making project updates manageable for executives without requiring code changes.

My contribution

I helped implement React and Tailwind pages, connected Community Projects to a custom Sanity schema, and contributed component and end-to-end tests.

The result

A content-driven project showcase with a dedicated editing interface. Published entries become consistent, responsive cards on the public site.

Content modeling & editor access

The custom project schema captures each entry’s title, description, creators, website, and image. Keeping these fields in Sanity separates editorial updates from the React source and gives the frontend a consistent content structure.

Google OAuth provides access to the Studio for authorized club executives. Editors maintain project information in the CMS, and the frontend fetches the published entries for the Community Projects page.
