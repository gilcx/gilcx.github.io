Handfluence

An accessibility concept designed to help Deaf, DeafBlind, and hearing people communicate in critical settings. My contribution was the live ASL-to-English recognition pipeline, built with OpenCV, MediaPipe Hands, and a custom LSTM.

From camera to text

Camera capture

OpenCV receives a live 1080p, 60 FPS video stream.

Hand landmarks

MediaPipe detects the hand and returns landmark coordinates.

Feature shaping

Landmarks are flattened and reduced from x, y, z to x and y.

Sliding window

The newest landmarks enter a rolling 90-frame buffer.

LSTM inference

The complete sequence is classified as an ASL alphabet letter.

Text output

Stable letters form words, followed by optional dictionary correction.

Dataset and model

Purpose-built training data

I recorded my own ASL alphabet sequences and passed each frame through MediaPipe Hands. The resulting landmark coordinates were flattened, reduced to x and y values, and stored as JSONL records for repeatable training.

Learning motion over time

A custom LSTM processes 90 consecutive landmark frames rather than treating each image as an isolated pose. The temporal window lets the model use both hand position and movement when predicting the current letter.

Prototype in action

Beyond letter-by-letter spelling, I also experimented with full-word LSTM recognition. Saved landmark sequences could be replayed from JSONL for inspection, while the live pipeline classified complete signed words.

Making live recognition usable

Debounced predictions

Transitions between letters can briefly resemble unrelated gestures and produce low-confidence guesses. A debounce layer suppresses these unstable transition predictions so they are not immediately added to the output.

Human-controlled word correction

After a short completion timeout, an English dictionary compares the spelled token with likely alternatives. The user can select the intended word or keep the original spelling for names and uncommon terms.

The full Handfluence concept
